# Ianis Delimar Martell · Power Solar — landing

Sitio estático (HTML + CSS + JS) de la promoción "Mitad del pago por 6 meses".
Formulario rápido de 1 paso: nombre, teléfono, pueblo y cuánto paga de luz → abre WhatsApp de Ianis con los datos.

Configuración en `js/main.js`:
- `whatsapp`: número de Ianis (17873674582)
- `leadEmail`: (opcional) email para recibir copia de cada cliente vía FormSubmit
- `promoEnds`: fin de la promoción

Se publica en Vercel como proyecto aparte con *Root Directory* = `ianis`.
